### UNIX
**Unix** - a family of multitasking, multi-user operating systems, known as the first portable operating system
- first written in Assembly, then revised in C programming lang in 1973
**Unix philosophy**
1. modular design
2. each tool performs a well-defined function
3. inode-based filesystem
4. inter-process communication known as "pipes"
5. shell scripting and command language
6. plain text for storing data
7. hierarchical file system
8. treats devices and certain types of communication as files
9. small programs strung together through CLI using pipes
10. treats all kinds of files as byte arrays

- "the idea that the power of a system comes more from relationships among programs than from the programs themselves"
- Unix env and client-server program model were essential in the development of the internet
- Unix consists of many libraries and utilites and **the kernel**
**kernel** - the master control program, provides services to start and stop programs, handles file system
and other "low-level" taks, schedules access to resources to avoid conflicts among programs
