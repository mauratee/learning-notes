## UNIX SYSTEMS PROGRAMMING, THE BIG PICTURE
***Program*** - a piece of code that runs in a computer
- Data flows into the program, program does something, data comes out of the program
- several users and several programs are running at once in most computers
***Operating System*** - role is to manage and protect all resources and to connect various devices to various programs
- the code for the operating system lives in the computer's memory
- computer memory provides space to store programs and data
1. system space - where the operating system is stored
2. user space - where user programs are stored
Operating System = Kernel!
- programs get data by asking the kernel
- kernel has sole access to all hardware and devices
- kernel provides access via services for programs to connect to external objects
